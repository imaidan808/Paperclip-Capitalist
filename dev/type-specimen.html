Type specimen for the UI pass

Roadmap item 4. The author's direction (2026-11-09): modern, clean-cut and professional, "not arcade or entertainment game styled", with the game's twist kept. These are the game's own components, set three ways. Only the type changes: colors, plates, shadows and spacing are the shipped ones, so the difference you see is the face, the case and the weight.

What each route is

  • Today. System sans for body text; headings, buttons, tabs, chips, badges and numbers in a monospace stack, with uppercase wide-spaced labels (css/styles.css, repeated in ui-draft.css, ui-deal.css, ui-academy.css). The roadmap names this as the likely source of the arcade or terminal feel.
  • A. One clean sans. The system's UI sans for everything, sentence case instead of capitals, tabular figures kept so columns still align. Zero bytes, zero requests.
  • B. Sans, with a serif for headings. Route A with the system serif on headings, the big figures and the result line, for a measured, editorial voice. Also zero bytes. The face differs by platform (New York on Apple devices, Georgia or Palatino elsewhere), so the look is close but not identical across a class's laptops.
  • C. A self-hosted font file (not shown). Gives one look on every device, at a price: each file is a request and bytes. Nothing was downloaded or measured for this page. Candidates whose licenses allow bundling are the SIL Open Font License families (Inter, IBM Plex Sans, Source Sans 3 and Public Sans are all published under it; confirm the exact file's license before use). No outside font service, by the site's rule.

What wiring a route costs

  • Budget. The first screen is 308 of 320 KB gzipped and the whole site 1,110.3 of 1,111 KB on 2026-11-16 (docs/ROADMAP.md). A or B change CSS only. C raises the whole-site limit, in its own pull request, with the number and the date written in docs/ARCHITECTURE.md.
  • Geometry. New metrics move every layout test that pins geometry (tests/), and the wider letterforms of a proportional face wrap where a monospace one did not: check the dock's tabs on a 390 px phone and the Deal Room's Read screen first.
  • The canvas. The world's own text sets its own monospace (js/world/labels.js, overlay.js, mapmode.js), and the glyph captions follow; a CSS-only route leaves those unchanged until they are moved with it.
  • Where the face is set. Four sheets repeat the monospace stack (styles.css, ui-draft.css, ui-deal.css, ui-academy.css): a route becomes one --face and one --head token read by all four, instead of a stack written in each place.
