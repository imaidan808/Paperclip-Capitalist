You are continuing "Paperclip Capitalist", a vanilla ES-module browser game for university entrepreneurship courses (a 90-day trading simulation, a 2.5D canvas world, an Academy tutorial, a classroom mode with a relay and a generated sound layer), in the public repository imaidan808/Paperclip-Capitalist. The live site is GitHub Pages, built from `main`: https://imaidan808.github.io/Paperclip-Capitalist/ (the address is case-sensitive). `assets/build.json` on the live site names the commit it was built from.

HOW WORK SHIPS. Branch from `origin/main` and open a pull request; the author merges it. Never push to `main`, never merge, never publish with the manual `skip_tests` path. A push to `main` runs `.github/workflows/pages.yml`: the whole suite (the `test` job, about 17 minutes), then the deploy; a red gate deploys nothing (`gh run view ID --log | grep "not ok"` finds the test). Pages caches for ten minutes, so after a deploy ask for a hard reload. Commit with the GitHub noreply identity already in the history, never a personal email.

READ FIRST: `git log --oneline -20 origin/main`, the open pull requests, then `docs/ARCHITECTURE.md` (modules, budgets, the world), `docs/V2_DESIGN.md` (the design contract), `docs/COPY.md` (the voice of every word a player reads) and, as the work needs them, `docs/ART_DIRECTION.md`, `docs/RENDER_PLAN.md`, `docs/AUDIO.md`, `docs/BALANCE.md`, `docs/FACULTY_KIT.md` and `docs/HOSTING.md`. `docs/CLOUD_HANDOFF.md` and the rest of `docs/handoff/` are the record of the cloud session of 2026-10-29 and 2026-10-30: the jobs in them were taken up in later pull requests, so read them as history and trust `git log` and the code over their status lines.

SETUP AND TESTS. `cd server && npm install` (the relay tests need `ws`; without it about 24 tests skip). Headless Chrome is found by `scripts/chrome.mjs`. The whole suite is `node --test --test-concurrency=4 tests/*.test.mjs` (about 2,250 tests; with `PC_NO_BROWSER=1` it takes 3 to 4 minutes, with the browsers on much longer). The runner is the reference: a browser test that fails by timeout under load must be run alone before it is believed (`node --test --test-reporter=tap --test-name-pattern=NAME FILE`), and a measurement that holds only on a fast machine is a flake (`node scripts/world-raster.mjs --throttle 8 --gap 450` reproduces a slow one). Kill headless Chrome and servers by process id, never with `pkill -f`.

THE AUTHOR'S INTENT (keep to it). Everyone starts with one paperclip and $0 and picks perks with downsides; the game must teach, and its trades are skill-based (nothing is timing-only). It is sold to universities, so public copy never says "free". The art is a very simple, effective style in the manner of Untitled Goose Game: flat fills, no outline, no gradient, no highlight, no texture, silhouette first, matte but vibrant colors. People (`js/world/figure.js`) and nature (trees, bushes, clouds) are in it; buildings, props and cars are not yet. Every formula and teaching claim in a word a player reads is checked against the code.

BUDGETS. The whole site weighs at most 1,111 KB gzipped and the first screen at most 320 KB (`tests/page-budget.test.mjs`, `docs/ARCHITECTURE.md`; a limit is raised in the pull request that needs it, with the number and the date written in the architecture document); the world's memory ledger holds 160 MB (`js/world/gfx.js`). A measurement is taken in headless Chrome and says what it could not see: real hardware, Safari, Firefox, a trackpad, a screen reader.

WHEN YOU FINISH A PIECE: push the branch, open the pull request with what was measured and what was not verified, and say what needs the author's decision.
